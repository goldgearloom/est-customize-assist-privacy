プライバシーポリシー

Chrome 拡張機能「EST カスタマイズアシスト」（以下「本拡張機能」）の、情報の取り扱いについて説明します。

制定日：2026年9月30日　最終更新日：2026年9月30日

1. 開発者のサーバーについて

本拡張機能は、開発者が運営するサーバーを使いません。利用者の入力・kintone の情報・API キーを、開発者が受け取ることはありません。アクセス解析や広告のためのデータ収集も行いません。

2. 読み取る情報

  • 開いている kintone アプリのフィールドの定義（フィールドコード・フィールド名・種類・選択肢）。kintone の「フォームの設定を取得する」API で読み取ります。
  • レコードのデータは読み取りません。ただし「テスト入力」機能では、レコード追加画面の入力欄の状態をページの中で読み、テスト用の値を入れます。この値はページの外に出しません。

3. 外部に送る情報

送り先送る情報送るとき
Google（Gemini API）
利用者が設定画面で選び、送信を許可した AI		 ・利用者が選んだ「やりたいこと」と条件
・使う項目の仮の名前（F01 など）と種類。実際のフィールドコード・フィールド名・選択肢の値は送りません
・利用者が自由に書いた文章（フィールド名・選択肢・登録した伏せる語句は仮の名前に置き換え、メールアドレス・電話番号・kintone のドメインなどは「[MASKED]」に置き換えた後のもの）
・利用者の API キー（認証のため）		 利用者が送信内容の確認画面で「この内容で送信」を押したときだけ
サイボウズ株式会社の kintone Documentation MCP（Gemini が呼び出す） 公式ドキュメントを探すための検索語（API やイベントの一般的な名前） Gemini が回答を作る途中で
利用者の kintone 環境 作成した JavaScript ファイル 利用者が「アプリに適用」の確認画面で「適用する」を押したときだけ

自由に書いた文章に、仮の名前に置き換えられない会社名・人名などを書いた場合は、そのまま送られます。送信内容の確認画面で、送る全文を確かめてから送信してください。

Google に送った情報は、Google の利用規約・プライバシーポリシーに従って扱われます。本拡張機能は送信時に「保存しない」（store: false）を指定しています。Gemini API の無料枠では、入力内容がサービスの改善に使われる場合があります。

4. この端末に保存する情報

情報保存先
API キー、使う AI とモデルの設定、伏せる語句、デバッグ記録の設定Chrome の拡張機能用ストレージ（この端末だけ。同期はしません）
作成中の入力内容ブラウザーを閉じると消える一時的な領域
「アプリに適用」の元に戻すための情報（適用前のファイルの一覧）と、適用したファイルが使う項目（フィールドコード）Chrome の拡張機能用ストレージ（この端末だけ）

仮の名前と実際の名前の対応表は保存しません（サイドパネルを閉じると消えます）。拡張機能を削除すると、保存した情報もすべて消えます。

5. 利用者のブラウザーで動かすコード

「このブラウザで試す」機能を使うと、利用者が確認した生成コードを、対象の kintone アプリの画面でだけ、利用者のブラウザーで一時的に動かします。「試すのをやめる」・サイドパネルを閉じる・ブラウザーの再起動で止まります。

6. Chrome ウェブストアのユーザーデータに関するポリシーの遵守

本拡張機能による情報の使用は、限定的使用の要件を含む Chrome ウェブストアのユーザーデータに関するポリシーに準拠します。
The use of information received from this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

  • 情報は、kintone のカスタマイズを作る目的のためだけに使います。
  • 情報を販売したり、広告に使ったりしません。
  • 開発者が利用者の情報を読むことはありません。
