はじめての使い方

Chrome 拡張機能「EST カスタマイズアシスト」を初めて使う方向けの案内です。インストールから、最初のカスタマイズを作ってアプリで動かすまでを説明します。

現在はベータ版です。画面や機能は変わることがあります。（この案内は 2026年10月の画面に合わせています）

この拡張機能でできること
  • 「やりたいこと」（項目の表示・非表示、保存前の入力チェック、自動計算など）を選んで条件を入れると、AI が kintone の公式ドキュメントを確かめながら、カスタマイズの JavaScript を作ります。
  • 作ったコードは、そのままアプリに登録したり、自分のブラウザーでだけ試したりできます。
  • kintone の仕様の質問（kintone仕様Q&A）や、フィールド一覧・テスト入力などのツールもあります。

1. インストールする

  1. Chrome ウェブストアのページを開き、Chrome に追加を押します。
  2. Chrome の右上のパズルの形のボタン（拡張機能）から、「EST カスタマイズアシスト」をピン留めしておくと便利です。
  3. アイコンを押すと、画面の右にサイドパネルが開きます。

2. AI の API キーを用意する

この拡張機能は、利用者ご自身の AI の API キーで動きます。次のどれか1つを用意してください。料金や利用条件は、それぞれの会社の規約に従います。

AIAPI キーを作るページメモ
Google GeminiGoogle AI Studio無料枠があります。無料枠では、送った内容が Google のサービスの改善に使われ、人が読むことがあります。業務で使う場合は有料枠を使ってください。無料枠は1日に送れる回数に上限があります。
Anthropic ClaudeClaude Console有料です。組織全体のキー（ワークスペースに属さないキー）を使う場合は、設定画面の「ワークスペースID」も入れます。
OpenAIOpenAI Platform有料です。この拡張機能では、OpenAI での動作をまだ確かめていません（試験的）。

API キーは、このパソコンの Chrome の中にだけ保存します。選んだ AI 以外には送りません。

3. 設定画面で保存する

  1. サイドパネルの右上の ⚙（または最初の画面の 設定画面を開く）を押します。
  2. 「使うAI」で AI を選び、「APIキー」に用意したキーを貼り付けます。「モデル」はふだんは（標準）のままでかまいません。
  3. 接続を確かめるを押すと、キーとモデルが使えるかをその場で確かめられます（文章は送りません）。
  4. 保存を押します。その AI への送信を許可するか聞かれたら、許可してください。

4. 最初のカスタマイズを作る

はじめは、テスト用のアプリで試してください。アプリの設定画面の「アプリを再利用」などで、本番のアプリを複製しておくと安心です。
  1. kintone で、カスタマイズしたいアプリ（一覧の画面やレコードの画面）を開きます。サイドパネルの上に、アプリの名前が出ます。
  2. 「作成」タブで、次の順に進みます。
    • やりたいこと：作りたいものを選びます（例：「項目の表示・非表示」）。
    • 適用画面：動かす画面（レコード追加・編集、詳細、一覧など）を選びます。種類によっては表示されません。
    • 依頼内容：対象の項目や条件を選びます。条件は kintone の絞り込みと同じ形で入れられます。下の「依頼のまとめ」で内容を確かめられます。
    • 送信確認：送信内容を確認を押すと、AI に送る内容の全文が出ます。項目名などは「F01」のような仮の名前に置き換わっています。確かめて この内容で送信を押します。
    • 結果確認：できたコードと説明、根拠のドキュメント（「確認済み」「未確認」）が出ます。

「やりたいこと」にないことは、「自由に依頼する」で文章で頼めます。そのとき、お客様の名前や社外秘の内容は書かないでください（項目名などを除き、書いたとおりに AI に送られます）。

5. 動かしてみる

方法内容
このブラウザで試す（試用機能）アプリの設定は変えずに、自分のブラウザーでだけコードを動かします。Chrome の拡張機能の詳細画面で「ユーザースクリプトを許可」をオンにする必要があります。試している間に保存したレコードは、実際のアプリに保存されます。
アプリに適用アプリの管理権限があれば、ファイルの登録からアプリの更新まで行います。前に作った同じ種類のファイルを外すか残すかも選べます。適用した後は 元に戻すもできます。
ダウンロードコードをファイルで保存します。アプリの管理者に登録を頼むときに使います。

思いどおりに動かないときは、結果の画面の「修正を頼む」で直してほしいことを書いて送ると、続けて直せます。

6. kintone仕様Q&A とツール

  • kintone仕様Q&A：kintone の機能や JavaScript API の仕様を質問すると、公式ドキュメントで確かめて答えます。
  • ツール（AI を使わず、外部にも送りません）：フィールド一覧（フィールドコードのコピー）、テスト入力（条件に合う値・合わない値を入れる）、コード点検（貼り付けたコードの書き方の誤りと、アプリにない項目を探す）、適用中のJS、作成の履歴。

7. 安全に使うために

  • レコードのデータは読み取らず、送りません。項目名・選択肢は仮の名前に置き換えて送ります。
  • メールアドレス・電話番号などは自動で隠します。会社名など、いつも隠したい言葉は設定画面の「伏せる語句」に登録してください。
  • 送る前に、AI に届く全文を必ず確認できます。気になる言葉は 選んだ文字を伏せるで隠せます。
  • 業務で使う場合は、有料の API をおすすめします。詳しくはプライバシーポリシーをご覧ください。

8. 困ったとき

こんなときこうしてください
「APIキーが正しくないようです」キーをもう一度コピーして貼り直し、設定画面の 接続を確かめるで確かめてください。
「利用の上限に達しました」無料枠の1日の上限などです。表示された時間がたってから使うか、有料枠にしてください。
「混み合っています」少し時間をおいて、もう一度送ってください。
「公式ドキュメントのサーバーにつながらなかった」答えの一部が確かめられていません。しばらくたってから、もう一度送ってください。
項目が出てこないkintone のアプリの画面を開いてから、サイドパネルを開き直してください。
「アプリに適用」できないアプリの管理権限が必要です。ダウンロードして、アプリの管理者に登録を頼んでください。
「このブラウザで試す」が使えないChrome の拡張機能の詳細画面で「ユーザースクリプトを許可」をオンにしてください。
